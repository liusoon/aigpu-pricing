# GPU 服务器租赁定价台

基于市场采购价与租赁行情，计算 NVIDIA GPU 8 卡整机（RTX 5090 / RTX PRO 6000 / H100 / H200 / B300）的**短租**与**长协闭口**每月租赁定价。行情锚点：2026-08-28 当周。

## 定价模型

- **短租（随行就市）**：月租 = 现货行情 × 短租系数（1 个月 ×1.00 / 季租 ×0.95 / 半年 ×0.90）；时租 = 月租 ÷ 720h ÷ 8 卡 × 时租溢价系数 1.35
- **长协闭口（价格锁定）**：月租 = 采购价 × 租期系数 + 托管常数（1 年 4.5% / 3 年 2.6% / 5 年 2.0%）；期满按采购价 10% 残值回购
- **交叉校验**：vs 云商折月价（时租 × 8 × 730h × 汇率）折价率 + vs 现货月租行情偏离度预警

所有行情输入与参数均可在页面直接修改，结果实时重算。
